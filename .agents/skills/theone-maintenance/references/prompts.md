# 项目任务提示词

将方括号替换为当前问题和验收条件；只选相关模板。

## 控件修复

使用 $theone-maintenance 修复 [控件与复现步骤]。先检查控件、主题及预览中的实际行为，保留原生输入、焦点、命令和公共 API。验收：[期望行为]。按影响范围验证明暗主题和三档尺寸，必要时使用真实输入与截图，更新相应控件文档。

## 图表绘制

使用 $theone-maintenance 修复 [图表类型] 在 [尺寸、宽高、字体和数据] 下的 [绘制问题]。同时检查实际文本／图形边界、轴标签、标题、图例、缩放与导出。以窄视口像素验证证明问题已解决，保留数据坐标、命中与采样语义，更新图表文档。

## DataGrid AOT

使用 $theone-maintenance 处理 [警告或行为问题]。从实际发布日志追到源码，不使用 NoWarn、警告抑制或整程序集保留。保留编译绑定、编辑、排序、筛选和虚拟化；按涉及路径运行真实 NativeAOT 专项，并记录注册或转换契约变化。

## 平台启动

使用 $theone-maintenance 修复 [平台、配置、启动方式] 的 [生命周期或启动问题]。检查项目输出类型、入口及平台产物，覆盖 Debug / Release；区分跨平台产物检查和目标宿主运行，给出准确的复核步骤。

## 交付复核

使用 $theone-maintenance 复核当前改动：按影响范围补足验证，核对公共契约、文档链接、平台证据和仓库清洁度。只报告有证据的结论；Git 推送或 NuGet 发布按本次明确授权执行。

配置方式依据 [OpenAI 的仓库维护 Skill 指南](https://developers.openai.com/blog/skills-agents-sdk)：根 AGENTS.md 承载项目约定，`.agents/skills/` 承载按需工作流。
