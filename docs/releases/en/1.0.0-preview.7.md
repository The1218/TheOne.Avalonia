# 1.0.0-preview.7

[简体中文](../zh-cn/1.0.0-preview.7.md) · **English** · [Documentation](../../README.md)

This release publishes source and release notes and prepares the coordinated `TheOne.Avalonia` and `TheOne.Avalonia.DataGrid` packages for manual NuGet upload. A GitHub Release does not imply NuGet availability. The baseline remains .NET 10 / Avalonia 12.1.4; main AssemblyVersion 1.0.0.0 and upstream DataGrid 12.1.2 / assembly identity 12.1.2.0 remain unchanged.

## Changes since preview.6

- Added [TreeSelect](../../controls/en/tree-select.md): stable-key single/multiple selection, Independent/Cascade checks, parent three-state, ancestor-preserving search, disabled selections, bounded tags, keyboard and virtualized rows. TreeSelectNode and typed adapters retain original models with compiled templates. Source replacement, Reset/Replace, selection and expansion reconcile by key. Includes a separate preview, Home entry and bilingual API/usage references.
- [Button, ToggleButton and RepeatButton](../../controls/en/basic.md#button-semantic-colors-and-appearances) and [IconButton](../../controls/en/icon-button.md) separate semantic colors from appearances, supporting `danger outline`, `success soft` and explicit `solid`. Color precedence: info > warning > success > danger > primary/accent. Appearance precedence: gradient > soft > outline > link > ghost > solid, independently of insertion order. Native three-state, hold repetition, icon placement and loading behavior remain.
- [Tag](../../controls/en/tag-verification-step.md) adds pill, square, dashed, dot and gradient. Dynamic status/variant/classes/theme/disabled changes no longer leave stale colors, corners or dashes.
- [TabControl](../../controls/en/collections.md) uses 8-DIP default content Padding across ordinary/card/One.CardTabControl themes. Runtime template replacement releases the old visual host before native reattachment, retaining content instances, edit values and selection; reattached headers refresh theme and density.
- [ColorPicker](../../controls/en/color-picker.md) Custom popups use natural content height instead of the generic 480-DIP Flyout cap. Native positioning and scrolling remain available for constrained space.
- Saved the [control/chart roadmap](../../plans/control-and-chart-roadmap.md), separating missing controls/types from shared axis/data-mapping capabilities. Planned items are not shipped features.
- DataGrid has no behavior changes in this release; it follows the shared package version.

## Upgrade notes

```sh
dotnet add path/to/YourApp.csproj package TheOne.Avalonia --version 1.0.0-preview.7
```

1. Upgrade any explicit companion DataGrid reference together; do not combine it with the official same-assembly package. No new NuGet dependency was introduced.
2. Standalone button classes retain enabled appearances; disabled colors intentionally converge on DisabledSurface/DisabledText/Line, with DisabledSelection for checked/null ToggleButton. Review pages depending on old special disabled colors. Use `primary solid` for a consistent solid appearance across button types rather than assuming legacy `primary` matches everywhere.
3. Explicitly set TabControl Padding if a page needs its previous spacing. Existing local Padding wins; demos no longer add redundant content margins.
4. Persist TreeSelect business keys, not display names or row wrappers. Use typed getters for custom models. A null source can hold initial pending keys; the first non-null source prunes missing keys. Cascade stores enabled leaves, retains preselected disabled leaves, and is not limited by search results.
5. TreeSelect model refresh scans the complete tree; views are virtualized, not fetching. Hosts own async child requests, cancellation and authorization. Map, radar, heatmap and other roadmap items are not implemented by this release.

## Verification and delivery limits

Release preparation builds required projects and checks documentation, package metadata and repository state; no full-control regression was run. Earlier scoped results: Tag 50,780 checks and 192 rendering comparisons; TabControl 5,725; Button 25,695; ToggleButton/RepeatButton/IconButton 175,119 each in managed and osx-arm64 AOT execution; ColorPicker 84; TreeSelect 172 each in managed and osx-arm64 AOT execution. The 10,001 expanded-node test realized seven row containers for its specific viewport, not every possible viewport.

Layout/input ran on macOS ARM64 with Avalonia.Headless and real Skia drawing, not Windows/Linux desktop or physical touch devices. TreeSelect implements touch/inertia containment; actual scrolling input checks exercised wheel events. Native AOT consumer checks emitted no new trimming warnings. The existing unrelated LoginDemoViewModel CS8620 build warning remains.

Upload `TheOne.Avalonia.DataGrid` before `TheOne.Avalonia`, then wait for NuGet validation and indexing. Package repository commits identify the matching source. Packages and SHA-256 checksums are attached to the Release.
