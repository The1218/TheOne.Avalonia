# 1.0.0-preview.6

**English** · [简体中文](../zh-cn/1.0.0-preview.6.md) · [Documentation index](../../README.md)

This release prepares matching `TheOne.Avalonia` and `TheOne.Avalonia.DataGrid` packages. NuGet upload is manual; a GitHub Release or local package does not mean it is available on NuGet. The baseline remains .NET 10 / Avalonia 12.1.4, with upstream DataGrid 12.1.2 and unchanged assembly identities.

## Changes since preview.5

- Adds [QRCode](../../controls/en/qr-code.md): UTF-8/ECI encoding, exact correction levels, quiet zones and vector drawing. Invalid content clears the previous symbol and reports an error.
- [ReportDesign](../../controls/en/report-design.md) gains static and field-bound QR elements. Design, multi-page preview and PDF share payload resolution and encoding; save/load, source replacement, undo/redo and concurrent exports retain isolated content.
- The validated data-source wizard branches on authentication requirements and separates authentication, Token/header selection, data requests and field selection. Configuration changes, cancellation and retries isolate stale responses. Table-column insertion/removal preserves widths, fields, selection and undo history.
- PDF export preserves previous destination content until commit. Local saves stage a same-directory temporary file and handle overwrite, occupied targets, permissions, cancellation and retry. Provider-specific limits and failure handling are documented.
- [WorkflowEditor](../../controls/en/workflow-editor.md) adds bound approver/role multi-selection, typed key/text adapters and stable `SelectedKeys` arrays. Custom inspectors reuse built-in field editors for consistent readonly, warnings, references and undo. Compact palette items and native side splitters retain per-instance preferred widths.
- Gantt single-task changes avoid full tree/subscription rebuilds. Charts incrementally maintain subscriptions, ranges, stacks, sampling and drawing caches. See [rendering measurements](../../controls/en/chart-rendering.md) for conditions, before/after data and remaining ScatterChart raster p99 limitations; this is not a universal p99 improvement claim.
- Ordinary template bindings are explicit `CompiledBinding`; native `TemplateBinding` remains. Concrete template types improve property recognition. DataGrid template changes are recorded in its vendor README.
- Removes historical PreviewHost verification/consumer probes and Program/App test argument branches, retaining normal demo startup. Updates control previews, bilingual APIs and migration guidance.

## Upgrade

```sh
dotnet add path/to/YourApp.csproj package TheOne.Avalonia --version 1.0.0-preview.6
```

Upgrade explicit `TheOne.Avalonia.DataGrid` references together and do not mix the official same-assembly package. The main package restores `Net.Codecrete.QrCodeGenerator` 3.2.1 transitively; third-party notices include its license attribution.

`WorkflowValueKind.MultiSelect = 3` and `ReportElementKind.QRCode = 8` append enum values. Existing ordinary documents remain readable, but older libraries cannot read documents containing the new types. Persisted multi-selections contain stable keys, not labels or runtime catalogs. The host owns execution, identity lookup and runtime data loading. Follow the [integration guide](../../integration/en/README.md) and control-specific contracts.

## Verification and delivery limits

Only affected controls were tested during implementation; no full regression was run for this release. Relevant guides retain measurement conditions and prior results. Latest WorkflowEditor layout checks passed 35 cases; inspector managed/native osx-arm64 AOT checks passed 32 each; bound-approver managed/AOT checks passed 128 each. Layout/input probes used Skia/Headless on the current macOS host, not Windows/Linux or physical-device execution.

Release preparation checks project builds, relative documentation links, package versions/dependencies/assembly identities and repository commit metadata. These are not full runtime regression claims. Old build trees, screenshots, logs and PDF artifacts were removed while retaining useful probe sources, concise reports and performance measurements.

Upload `TheOne.Avalonia.DataGrid` before `TheOne.Avalonia`, then wait for NuGet validation/indexing. Package repository metadata identifies the source commit; a SHA-256 manifest accompanies the packages.
