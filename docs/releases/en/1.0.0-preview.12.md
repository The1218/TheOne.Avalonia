# 1.0.0-preview.12

[简体中文](../zh-cn/1.0.0-preview.12.md) · **English** · [Documentation](../../README.md)

- ChartBase charts use clearer title, axis and legend typography. Area fills fade, unstacked bars have rounded value ends, and radar labels avoid overlap.
- Hover feedback animates highlights and slice lift while the pointer, crosshair and hit test respond immediately. The chart and application motion settings control these transitions.
- In Auto mode, entry motion follows the chart type. Bars grow from the baseline, pie and doughnut sectors sweep clockwise, and gauges advance from their minimum. The [chart rendering guide](../../controls/en/chart-rendering.md) describes each animation mode.

This preview pairs TheOne.Avalonia with TheOne.Avalonia.DataGrid and requires .NET 10 and Avalonia 12.1.4. Upgrade both packages together.

```sh
dotnet add path/to/YourApp.csproj package TheOne.Avalonia --version 1.0.0-preview.12
```
