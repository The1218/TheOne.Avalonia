# 1.0.0-preview.4

**English** · [简体中文](../zh-cn/1.0.0-preview.4.md) · [Documentation](../../README.md)

This release prepares matching `TheOne.Avalonia` and `TheOne.Avalonia.DataGrid` packages. Availability depends on the NuGet feed. The baseline remains .NET 10 / Avalonia 12.1.4; upstream DataGrid remains 12.1.2 and assembly identities are unchanged.

## Changes since preview.3

- Control guides and individual previews present labeled Classes examples, project-added properties, business APIs and related models. Properties and actions include short snippets; shared sizing and motion are centralized on Home. Adds the Description list and integration/migration guidance.
- MultiSelectBox popups use a bounded viewport and contain wheel input, preventing outer-page scrolling. Overflow shows the native vertical scrollbar.
- Fixes tab headings disappearing after a drop beyond the last heading, and virtualized item attachment, selection identity and stale data after reorder, removal/reinsertion, Replace, Reset and ItemsSource changes.
- Compact menu scroll buttons and full short-menu measurement fix incorrect first-open native ContextMenu sizing, unnecessary arrows and clipped text. Large menus remain virtualized; panel changes release old containers first.
- Updates bilingual menu/collection lifetime guidance while retaining window ownership, message routing, theme switching and optional editor/printing dependency documentation.

## Upgrade

```sh
dotnet add path/to/YourApp.csproj package TheOne.Avalonia --version 1.0.0-preview.4
```

Upgrade any explicit `TheOne.Avalonia.DataGrid` reference to `1.0.0-preview.4` as well. Do not also reference the official `Avalonia.Controls.DataGrid`. Consumer applications do not need PreviewHost, verification sources or a maintainer's local skills.

Existing theme, command and model-binding entry points remain unchanged. Custom ItemsPanel values or complete templates override the theme's layout; verify their initial measurement, bounded viewport and container lifetime. See the [integration guide](../../integration/en/README.md).

## Verification limits

Recent fixes use affected-control checks, not full regression. Native macOS menu first-open checks cover Light/Dark, three sizes, narrow windows and mixed row heights. Native layout/drawing, Headless pointer/keyboard interaction and osx-arm64 NativeAOT menu-consumer checks run separately. Physical desktop hover is limited by system permissions and is not reported as passed. Builds and cross-RID artifacts do not prove execution on Windows, Linux, mobile or browser targets.

Release preparation also checks paired language directories, documentation links, source-contract drift, business-snippet compilation and package metadata. The package nuspec repository commit identifies its exact source; complete XML API documentation is not included in the package, so use the [source contract](../../api/en/README.md) for precise declarations.
