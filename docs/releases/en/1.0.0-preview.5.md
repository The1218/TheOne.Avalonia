# 1.0.0-preview.5

**English** · [简体中文](../zh-cn/1.0.0-preview.5.md) · [Documentation](../../README.md)

This prerelease prepares matching `TheOne.Avalonia` and `TheOne.Avalonia.DataGrid` packages. NuGet upload is a separate manual step; availability depends on the feed. The baseline remains .NET 10 / Avalonia 12.1.4, with upstream DataGrid 12.1.2 and unchanged assembly identities.

## Changes since preview.4

- Adds [NavPage](../../controls/en/nav-page.md): NavMenu sidebar, retained card-tab pages, default home, compiled custom-model bindings, sidebar header/footer templates and an optional right header. A null right header leaves the entire right area to the tab body.
- Extends tabs with optional item icons, right-side pin indicators and close/pin/close-all context menus. Pinned pages cannot close or move; ordinary tabs cannot cross the pinned region. Reduces icon, close-glyph and header-padding sizes.
- Adds NavMenu expand/collapse transitions with reduced-motion support and preserves tab selection visibility during shell resizing.
- MultiSelectBox search projects cached entries without rebuilding source/model subscriptions or rereading selection. Model changes retain the existing selection and availability rules.
- WorkflowEditor adds graph indexes, cached node metrics and edge paths, viewport culling and a bounded inactive cache for default node views. Custom editors and focused nodes remain mounted to protect drafts and focus. Adds an entry to reopen the node toolbox.
- Popup boundaries contain fractional two-axis wheel input, touch-scroll gestures and inertia/end phases, including short lists, scroll boundaries and cached popup tails. Native internal scrolling remains available. Covers selectors, date/time pickers and affected navigation menu popups, including the ReportDesign authentication-header selector.
- Updates related bilingual guides, API references and per-control examples. Includes existing source formatting and using cleanup.

## Upgrade

```sh
dotnet add path/to/YourApp.csproj package TheOne.Avalonia --version 1.0.0-preview.5
```

Upgrade any explicit `TheOne.Avalonia.DataGrid` reference to `1.0.0-preview.5` together. Do not also reference the official `Avalonia.Controls.DataGrid` package. See the [integration guide](../../integration/en/README.md).

Existing theme-color enum APIs and native input behavior remain. Workflow viewport recycling is not data virtualization: model, metric and edge caches still scale with the document, initial layout measures all nodes, and custom editing views are intentionally retained. NavPage releases its own references when a page closes; the host owns ViewModel disposal.

## Verification limits

This release uses affected-control checks rather than full-library regression. macOS managed checks cover MultiSelectBox refresh behavior, WorkflowEditor indexes/viewports/selection, NavPage/tab behavior and popup input routing. Previous osx-arm64 NativeAOT NavPage consumer checks are distinct from this release's managed build and package inspection.

Touch/inertia checks use Avalonia's headless input and native gesture recognizers; physical touchpad behavior and Windows/Linux execution are not claimed as verified. The performance assessment is a future optimization plan, not an implementation or measured speed guarantee in this release. Exact source identity is recorded in each package's nuspec repository commit.

For manual upload, publish `TheOne.Avalonia.DataGrid` first, then `TheOne.Avalonia`, and wait for feed validation/indexing before testing remote consumption. Package hashes are supplied with the release artifacts.
