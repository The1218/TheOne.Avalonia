# 1.0.0-preview.9

[简体中文](../zh-cn/1.0.0-preview.9.md) · **English** · [Documentation](../../README.md)

This release prepares matching `TheOne.Avalonia` and `TheOne.Avalonia.DataGrid` NuGet packages for manual upload. A source push or local package does not establish NuGet availability. The baseline remains .NET 10 / Avalonia 12.1.4. Main assembly version stays 1.0.0.0; upstream DataGrid and its assembly remain 12.1.2 / 12.1.2.0.

## Changes since preview.8

- Adds [Heatmap, Radar, Funnel](../../controls/en/chart-specialized.md), [BoxPlot, Candlestick](../../controls/en/chart-statistical.md), and [Treemap, Sunburst](../../controls/en/chart-hierarchy.md), with observable models, theme resources, selection/hit testing, export, hierarchy drill navigation, independent previews and bilingual contracts. These seven additions do not imply complete ECharts coverage.
- Charts share animation configuration for initial presentation and subsequent changes, respecting disabled controls, reduced motion and complex-data budgets. Subscription, range, geometry, text and drawing caches are improved. See the [first batch](../../controls/en/chart-echarts-performance-20261020.md) and [second batch](../../controls/en/chart-next-batch-performance-20261020.md) performance records for methods, semantics and limits.
- [AttachmentList](../../controls/en/attachment-list.md) adds multiple-file selection, bindable files, status/progress, preview events and removal commands, with explicit cancellation, late-result and file-ownership rules. Hosts still own transport, authorization and business attachment relationships.
- [WorkflowEditor](../../controls/en/workflow-editor.md) adds a connection property template, connection factory, node creation/deletion policies and observable connection metadata integrated with revisions, undo/redo and serialization. [DialogContext](../../api/en/TheOne.Avalonia.Controls.DialogContext.md) exposes computed-property change notification to subclasses.
- [DataGridRowNumbers](../../controls/en/datagrid-extensions.md) adds opt-in native row-header numbering, paging offsets and width configuration, responding to sorting, filtering and container reuse, and restoring original settings when disabled. This is a main-library extension; vendor DataGrid behavior is unchanged.
- Preview descriptions/examples are created when needed. Visited pages retain instances to avoid remounting descriptions and code editors on return, preserving drafts, selection, caret, focus and undo history. Removes the shared bottom source expander and empty reference placeholders; short inline snippets remain in `Description`. The [return measurements](../../controls/en/preview-return-performance-20261020.md) show p95 of 941.8→19.9 / 948.2→19.8 / 316.3→17.2ms for fully browsed Line / Button / NavPage pages on the documented macOS workload. The endpoint is the first native frame callback, not GPU presentation.
- Synchronizes bilingual guides, public contracts, preview catalog, installation and migration guidance. Removes historical duplicate builds, runtime copies and old packages while retaining useful verification sources and performance samples.

## Upgrade

```sh
dotnet add path/to/YourApp.csproj package TheOne.Avalonia --version 1.0.0-preview.9
```

1. Upgrade both packages together. Do not reference the official `Avalonia.Controls.DataGrid` package alongside this fork. No new production NuGet dependency is introduced; PreviewHost editor, printing and MVVM dependencies remain outside the library.
2. Statistical and hierarchy charts use their own models: OHLC, box summaries and trees are not ordinary XY points. Charts still draw directly without creating a Control per point.
3. Visited preview pages retain resources longer; no LRU eviction is introduced. Hidden pages do not lay out or draw, but business subscriptions can still receive updates. First-frame figures do not represent complete browsing cost, physical display latency or a universal upper bound.
4. After an attachment command accepts files, the host owns disposal and business cancellation. Persist workflows through `WorkflowSerializer.Save/Load`; hosts own execution, authorization and transport.

## Verification and publication boundaries

Release checks cover the PreviewHost build, bilingual contract generation/drift, business snippet compilation, local documentation links, package versions, dependencies, contents and repository commit metadata. This is not an all-control behavioral regression.

Feature-stage evidence includes 259 native animation assertions and 188 Headless+Skia checks for the first chart batch, plus 111 later edge checks; 57 statistical, 114 hierarchy and 7 position/budget checks for the second batch, with native pointer/key selection, zoom and drill interactions; and 151 native preview-return checks. Suites overlap and must not be summed as unique cases. Performance documents record actual DLL hashes, methods and unverified areas.

Attachment, row-number, workflow and dialog verification sources remain under `.preview/pengpai-*`; historical evidence is not represented as rerun in this release or as cross-platform execution. Release builds retain the existing `LoginDemoViewModel` CS8620 nullable warning. No Windows/Linux execution, all-control regression or whole-library AOT publish was performed for this release.

Upload `TheOne.Avalonia.DataGrid` first, then `TheOne.Avalonia`, and wait for validation/indexing. Packages include a SHA-256 manifest; their nuspec repository commit identifies the packaged source.
