# 1.0.0-preview.8

[简体中文](../zh-cn/1.0.0-preview.8.md) · **English** · [Documentation](../../README.md)

This release prepares matching TheOne.Avalonia and TheOne.Avalonia.DataGrid packages for **manual NuGet upload**. Source/GitHub release availability does not imply NuGet indexing. The baseline remains .NET 10 / Avalonia 12.1.4; main assembly version 1.0.0.0 and DataGrid upstream/assembly versions 12.1.2 / 12.1.2.0 are unchanged.

## Changes since preview.7

- [OneIcon](../../controls/en/one-icon.md): 320 built-in vectors in 20 categories, with 32 dedicated filled variants and explicit outline fallback for the rest. Enum/binding/theme/density support, catalog API and an independent gallery cover common, finance, industry, medical, infrastructure, transport, commerce, education and weather icons.
- The icon gallery reuses native virtualized rows and Button slots, caches text layout, and avoids unnecessary construction, binding and layout. In the documented 320-icon native macOS workload, opening p95 improved from 310.50ms to 143.56ms, scroll-update p95 from 33.48ms to 17.46ms, and median per-scroll UI allocation from 3,552,744 to 114,896 bytes. The endpoint is render-thread batch completion, not physical-display latency; see the guide for methodology and limits.
- [Breadcrumb](../../controls/en/breadcrumb.md): paths, icons, separators, original-item command parameters, noninteractive current item, keyboard/RTL, dynamic collections and compiled binding. Includes fixes for rapid input, command reentry, ancestor returns, source changes, reloads and delayed focus recovery.
- [DateTimePicker](../../controls/en/datetime-picker.md): native CalendarDatePicker-based combined input with Format, nullable Time, TwoWay binding, time preservation, cancel restoration and filled/disabled styles. Native validation, date limits and popup scroll isolation remain in use.
- [Timeline](../../controls/en/timeline.md): vertical event history with left/right/alternate layout, reverse arrangement, spacing, five states, custom markers/templates, observable TimelineItemModel and collection updates. Trailing connectors and template reversal follow current data while native content interactions remain intact.
- [OneWindow / ThemeButton](../../controls/en/windows.md): title-bar visibility, explicit theme scope and optional Default/Light/Dark cycling; preview branding/window layout updated without test-only startup arguments.
- Bilingual guides, API/model references, migration entry points, version notes and preview navigation follow source. Icon concept artwork is retained and clearly labeled; unimplemented chart/control proposals remain plans.
- Removed old builds, captures, logs, traces, reference-merge helpers and duplicate checkouts while keeping reusable local verification source. Production startup has no historical test-argument branches. DataGrid has no behavior changes and is repackaged for the coordinated release.

## Upgrade notes

```sh
dotnet add path/to/YourApp.csproj package TheOne.Avalonia --version 1.0.0-preview.8
```

1. Upgrade both packages together; do not also reference official Avalonia.Controls.DataGrid. No new production NuGet dependency was added. PreviewHost editor/printing/MVVM packages are not library dependencies.
2. Share icon geometry/metadata, not Control instances. Icons do not capture input by default. Filled uses separate resources only for explicitly supported glyphs.
3. Breadcrumb does not create pages or mutate paths. Update caller-owned navigation from commands/events and persist business keys rather than visuals/display labels.
4. DateTimePicker performs no time-zone conversion; date bounds are not precise timestamp limits. Normally bind SelectedDate only; avoid conflicting assignments when also binding Time.
5. Timeline follows collection order. Reverse affects visual order only, not native content Tab order. The default panel is not virtualized; paginate/load incrementally for large histories.
6. ThemeButton defaults to Light/Dark. Enable IsThreeState for system Default; IsChecked null/true/false correspond to Default/Dark/Light. Window/application switching respects explicit scope and native theme inheritance.

## Verification and publication limits

Release preparation builds PreviewHost and checks documentation links, generated contracts, package contents, coordinated versions/dependencies and source-commit metadata; it does not run full-library regression. Prior implementation evidence:

| Scope | Executed focused checks | Limits |
| --- | --- | --- |
| OneIcon | Managed/macOS ARM64 NativeAOT each 10,709; native desktop search, pointer/keyboard and scroll; six unchanged glyph atlases | Timings include scheduling, not Windows/Linux or physical presentation latency |
| Breadcrumb | Initial managed/AOT each 205; later lifecycle 534 and consecutive-input 570 | Later interaction-only changes did not repeat AOT; not all-platform execution |
| DateTimePicker | Managed/macOS ARM64 NativeAOT each 55 | Headless + Skia input/drawing, not Windows/Linux native windows |
| Timeline | Managed/macOS ARM64 NativeAOT each 426; native desktop interaction | Timeline/preview scope only |

These are actual prior feature checks, not a claim of rerunning all of them during packaging. The normal Release build retains the existing LoginDemoViewModel CS8620 nullability warning. Icon/Timeline native consumption introduced no trim/AOT warnings.

Upload TheOne.Avalonia.DataGrid first, then TheOne.Avalonia, and wait for NuGet validation/indexing. Packages have a SHA-256 manifest and repository commit metadata identifying source. A remote release, tag or local package does not establish successful NuGet upload.
