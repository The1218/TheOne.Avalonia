# 1.0.0-preview.11

[简体中文](../zh-cn/1.0.0-preview.11.md) · **English** · [Documentation](../../README.md)

This version produces coordinated TheOne.Avalonia and TheOne.Avalonia.DataGrid NuGet packages for manual upload. A source push and local package do not imply feed availability. .NET 10, Avalonia 12.1.4, main assembly 1.0.0.0 and DataGrid assembly 12.1.2.0 remain unchanged.

## Changes

- [OneIcon](../../controls/en/one-icon.md#icon-hosts-and-icontemplate) enum values work directly in IconButton, Tag, InfoCard, LoadingContainer, relation nodes, TabItem and NavPage icon fields. NavMenu templates can bind built-in glyphs from the complete navigation item. Custom IconTemplate, Geometry, compiled bindings and native content behavior remain supported.
- Fixes Geometry being displayed as text in Tag, InfoCard, relation nodes and TabItem after clearing a custom template. Typed fallback creates PathIcon; type, template and null changes clear the previous display.
- Fits and centers affected icon regions uniformly, including custom icons with explicit Width/Height. The default NavPage brand frame is 24 DIP and tabs retain 14 DIP; other hosts use their existing icon-size properties. NavMenu preserves text templates and icon template recycling.
- Disabled LoadingContainer supplies One.DisabledText to both OneIcon and Geometry, restoring the current accent on enable. Consumer local Foreground retains native Avalonia priority.
- Fixes the [ImageUpload](../../controls/en/image-upload.md) viewer being constrained twice by the generic Flyout size and scroll container. Header, close control and toolbar remain visible, with zoom, pan and Escape dismissal preserved.
- Includes ImageUpload, illustrated bilingual control guides, integration documentation and updated OneIcon/IconButton examples. Vendor DataGrid has a coordinated package version change only.

## Upgrade and upload

```sh
dotnet add path/to/YourApp.csproj package TheOne.Avalonia --version 1.0.0-preview.11
```

Upgrade both packages together and do not also reference official Avalonia.Controls.DataGrid. No production dependency was added. Supply a OneIconKind enum or Geometry to object-typed icon fields; the string `"Save"` is not converted to an enum. A OneIcon control instance still has one visual parent; prefer shared enum or Geometry values in navigation models.

Manually upload TheOne.Avalonia.DataGrid first, wait for indexing, then upload TheOne.Avalonia. Packages include source commit metadata and a SHA-256 manifest.

## Verification limits

Initial icon integration passed 1,776 assertions. Dynamic switching passed 9,204 assertions across 12 layout combinations. Each suite ran both on Headless+Skia and an executed osx-arm64 NativeAOT consumer; repeated backend runs are not independent additional cases. Coverage includes enum/Geometry identity, template replacement/clearing, explicit sizing and centering, theme changes while disabled, palette updates, local foreground priority and recycled NavMenu compiled bindings.

ImageUpload popup checks passed 236 assertions across 18 layouts on both Headless+Skia and the native macOS backend. Native wheel zoom, drag-to-pan and Escape dismissal were also verified. These results come from the corresponding implementation work; packaging does not expand runtime regression scope. Build, package metadata and payload checks run separately. No Windows/Linux execution, full behavior regression or full-library AOT publish is claimed.
