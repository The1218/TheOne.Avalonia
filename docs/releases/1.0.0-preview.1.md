# 1.0.0-preview.1

2026-10-14 · 预发布版 · .NET 10 / Avalonia 12.1.4

首个 TheOne 双包预发布版本，包含 Still 主题、独立图表和 DataGrid 扩展。预发布状态不代表所有 Avalonia 目标平台均已验收。

## 安装与 NuGet

两包已按 vendor、主库顺序发布，使用相同版本和预发布渠道：

- [TheOne.Avalonia.DataGrid 1.0.0-preview.1](https://www.nuget.org/packages/TheOne.Avalonia.DataGrid/1.0.0-preview.1)：基于官方 DataGrid 12.1.2 的源码扩展。
- [TheOne.Avalonia 1.0.0-preview.1](https://www.nuget.org/packages/TheOne.Avalonia/1.0.0-preview.1)：主题与扩展控件，自动依赖配套 DataGrid 包。

```sh
dotnet add package TheOne.Avalonia --version 1.0.0-preview.1
```

加载 `TheOne.Avalonia.Themes.OneTheme`；接入示例见 [README](https://github.com/The1218/TheOne.Avalonia/blob/1.0.0-preview.1/README.md)。Avalonia 核心、Skia 和 Fluent 依赖为 12.1.4；请勿同时引用官方 `Avalonia.Controls.DataGrid` 包。

## 主要功能

- **Chart**：14 种独立控件，覆盖折线、面积、柱状、横向条形、散点、饼图、环形、仪表及普通／百分比堆叠图。支持平滑曲线、缩放和平移、双 Y 轴、大数据采样、十字准线、多系列联动提示、图例显隐、数据更新动画及 PNG 导出；完善标签避让、首尾数据显示、扇区悬停、仪表指针／刻度和三档尺寸。
- **DataGrid 筛选**：表格属性开启，自动注册实体属性；列头按钮支持文本模糊搜索、数值精确匹配／范围筛选，多列条件与业务过滤组合，可清除列筛选。
- **DataGrid 布局与统计**：原生左右冻结列、列拖动反馈及边界处理；表格属性控制统计行显示，数值列单独开启合计、平均值、最小值、最大值和有效数值计数。统计随筛选、数据更新、编辑、分组及列布局同步，并保留原生行／单元格 Presenter 和虚拟化回收。
- **主题与扩展**：Still 语义色、Light / Dark 和 small / normal / large；完善小尺寸文本输入及按钮对齐。包含 NavMenu、InfoCard、窗口／登录窗口、消息／对话框、Tag 和 Step 等扩展及交互预览。
- **打包与维护**：统一双包版本来源，保留 vendor 程序集身份和强名称；消除稳定包依赖预发布 vendor 的 NU5104 组合，并将 NU5104 作为打包错误。文档按任务拆分，测试按影响范围选择，提供独立包消费与远程源验证脚本。

## 验证结果与平台边界

| 范围 | 已有证据 | 边界 |
| --- | --- | --- |
| NuGet.org 远程消费 | 仅公共源、隔离缓存，禁用 SDK 隐式离线源；两包版本和来源正确，除新增仓库签名外与验收包逐项一致；独立消费端构建零警告／零错误 | 无项目引用或 PreviewHost 链接；远程还原成功不等于所有平台实跑 |
| macOS ARM64 托管 | 本次远程消费 Headless 152 项、真实桌面 140 项通过；覆盖明暗主题、三尺寸、筛选／统计／左右冻结、千行容器数量及远距离回收 | 未穷尽人工拖动手感、系统缩放、多屏和 GPU 差异 |
| macOS ARM64 NativeAOT | 发布前，同版本本地包的真实原生程序通过 Headless 152 项、桌面 140 项；运行时动态代码关闭 | 远程发布后未重复 AOT 编译；原生发布仍有 13 条已记录的上游既有警告，未用 NoWarn 屏蔽 |
| Windows x64 / ARM64、Linux x64 / ARM64、macOS Intel | 阶段 5 完成框架依赖跨 RID 发布及目标架构／原生资源检查 | 属于阶段 5 基线，未作为本版重新跨 RID 打包证据；未在对应宿主实跑，也未验证对应 NativeAOT、输入、字体和 GPU |
| Android、iOS、浏览器、安装器、签名与公证 | 未纳入本次桌面验收 | 未验证 |

NativeAOT 消费端须显式编译列绑定、关闭自动列生成，并调用 `DataGridAot.PreserveRowType<T>()`。统计基于已加载数据的完整筛选结果（分页前）；服务端未加载的数据由业务端聚合。
