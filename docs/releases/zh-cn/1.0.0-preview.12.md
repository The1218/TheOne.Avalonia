# 1.0.0-preview.12

**简体中文** · [English](../en/1.0.0-preview.12.md) · [文档入口](../../README.md)

- 调整 ChartBase 系列图表的标题、坐标轴和图例层级。面积填充渐隐，非堆叠柱条的数值端收圆，雷达图数值标签会避让。
- 数据高亮和扇区抬起平滑过渡，十字线与命中结果即时响应指针。图表和应用的动效设置可关闭这些过渡。
- Auto 模式会按图形选择入场动效。柱条从基线长出，饼图和环形图顺时针展开，仪表从最小值过渡到当前读数。各模式详见[图表绘制指南](../../controls/zh-cn/chart-rendering.md)。

本预览版同步发布 TheOne.Avalonia 与 TheOne.Avalonia.DataGrid，需要 .NET 10 和 Avalonia 12.1.4。请同时升级两个包。

```sh
dotnet add path/to/YourApp.csproj package TheOne.Avalonia --version 1.0.0-preview.12
```
