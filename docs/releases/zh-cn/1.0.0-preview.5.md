# 1.0.0-preview.5

**简体中文** · [English](../en/1.0.0-preview.5.md) · [文档入口](../../README.md)

本预发布版同步准备 `TheOne.Avalonia` 与 `TheOne.Avalonia.DataGrid` 两个包。NuGet 上传由维护者另行手动完成，是否可安装以源的实际状态为准。框架仍为 .NET 10 / Avalonia 12.1.4，DataGrid 上游为 12.1.2，程序集身份保持不变。

## 相对 preview.4 的更新

- 新增 [NavPage](../../controls/zh-cn/nav-page.md)：集成 NavMenu 侧栏、保留页面状态的 Card 标签、默认首页、自定义模型编译绑定、侧栏 Header/Footer 模板与可选 RightHeader。RightHeader 为 null 时，标签内容占满右侧区域。
- Tab 增加可选 Item 图标、标题右侧固钉和关闭／固定／关闭全部右键菜单。固定页不可关闭、不可拖动，普通页不能越过固定区域；收紧图标、关闭符号和标题内边距。
- NavMenu 展开收缩增加过渡动画并遵守关闭动效设置；导航壳调整宽度时保持选中标签可见。
- MultiSelectBox 搜索仅投影缓存条目，不重建数据及模型订阅、不重新读取选择；保留模型更新、禁选和选择规则。
- WorkflowEditor 增加图索引、节点度量和连线路径缓存、视口裁剪及默认节点的有界冷缓存。自定义编辑内容和焦点节点保持挂载，保护草稿与焦点；补充重新打开节点工具栏的入口。
- 下拉弹层统一隔离双轴小数滚轮、触摸滚动手势及惯性／结束阶段，覆盖短列表、滚动边界和缓存弹层尾部事件；保留内部原生滚动。涉及选择器、日期时间选择及受影响导航弹层，也覆盖 ReportDesign 权限请求头下拉框。
- 同步相关双语指南、API 说明与独立预览；包含工作区既有的格式与 using 整理。

## 升级

```sh
dotnet add path/to/YourApp.csproj package TheOne.Avalonia --version 1.0.0-preview.5
```

显式引用 `TheOne.Avalonia.DataGrid` 的项目同步升级到 `1.0.0-preview.5`，不要同时引用官方 `Avalonia.Controls.DataGrid` 包。参见[接入指南](../../integration/zh-cn/README.md)。

保留现有主题枚举 API 与原生输入行为。Workflow 视口回收不等于数据虚拟化：模型、度量和连线缓存仍随文档规模增长，首次布局真实测量全部节点，自定义编辑视图有意保留。NavPage 关闭页时释放自身引用，ViewModel 资源释放由宿主管理。

## 验证边界

本版只执行受影响控件专项，不做全库回归。macOS 托管专项覆盖 MultiSelectBox 刷新、WorkflowEditor 索引／视口／选择、NavPage／标签和弹层输入路由。此前的 osx-arm64 NativeAOT NavPage 消费验证与本次托管构建、包检查分别说明。

触摸与惯性通过 Avalonia Headless 输入及原生手势识别器验证，不代表物理触摸板或 Windows／Linux 实跑通过。性能分析属于后续优化方案，不作为本版已实现功能或速度保证。准确源码以包内 nuspec 的 repository commit 为准。

手动上传时先上传 `TheOne.Avalonia.DataGrid`，再上传 `TheOne.Avalonia`；等待验证与索引完成后再检查远程消费。发布产物另附包哈希。
