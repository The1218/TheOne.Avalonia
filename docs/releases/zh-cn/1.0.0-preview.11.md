# 1.0.0-preview.11

**简体中文** · [English](../en/1.0.0-preview.11.md) · [文档入口](../../README.md)

本版生成 TheOne.Avalonia 和 TheOne.Avalonia.DataGrid 两个同版号 NuGet 包，由维护者手动上传。代码推送和本地打包不表示 NuGet 已上架。.NET 10、Avalonia 12.1.4、主库程序集 1.0.0.0 及 DataGrid 程序集 12.1.2.0 保持不变。

## 更新

- [OneIcon](../../controls/zh-cn/one-icon.md#图标宿主与-icontemplate) 枚举可直接用于 IconButton、Tag、InfoCard、LoadingContainer、关系图节点、TabItem 和 NavPage 的图标字段。NavMenu 支持在完整导航项模板中绑定内置图标。自定义 IconTemplate、Geometry、编译绑定及原生内容行为保留。
- 修复 Tag、InfoCard、关系图及清空模板后的 TabItem 将 Geometry 显示成文字的问题。默认回退统一创建 PathIcon；动态类型、模板及空值切换清除旧显示。
- 为受影响的图标区域补上等比居中适配，约束显式 Width/Height 的自定义图标，避免覆盖文字和溢出。NavPage 默认品牌图标框为 24 DIP，页签仍为 14 DIP；其他宿主沿用各自图标尺寸属性。NavMenu 保留文字模板和图标模板回收能力。
- LoadingContainer 禁用时，OneIcon 与 Geometry 的默认前景统一为 One.DisabledText；重新启用恢复当前主题强调色。消费方局部 Foreground 继续遵守 Avalonia 优先级。
- 修复 [ImageUpload](../../controls/zh-cn/image-upload.md) 查看弹层被通用 Flyout 尺寸和滚动容器重复约束的问题；完整展示标题、关闭按钮和工具栏，保留缩放、平移及 Esc 关闭。
- 包含 ImageUpload、控件图文指南及双语接入说明，完善 OneIcon 和 IconButton 预览示例。vendor DataGrid 本版仅同步包版本，无行为改动。

## 升级和上传

```sh
dotnet add path/to/YourApp.csproj package TheOne.Avalonia --version 1.0.0-preview.11
```

两包同步升级；不要并用官方 Avalonia.Controls.DataGrid 包。没有新增生产依赖。对象类型的图标字段请传入 OneIconKind 枚举或 Geometry，字符串 `"Save"` 不会自动转换为枚举。OneIcon 控件实例仍只能有一个视觉父级；导航模型优先共享枚举或 Geometry。

手动上传时先上传 TheOne.Avalonia.DataGrid，等待索引后再上传 TheOne.Avalonia。包附 SHA-256 清单和源码提交元数据。

## 验证边界

图标基础接入专项为 1,776 项断言；后续动态切换专项为 12 组布局、9,204 项断言，均分别通过 Headless+Skia 和 osx-arm64 NativeAOT 消费。同一套检查在两个后端重复运行，不能相加为独立用例总数。覆盖枚举及 Geometry 身份、模板覆盖/清空、显式尺寸及居中、禁用时切换主题、调色板更新、局部前景优先级和 NavMenu 回收后的编译绑定。

ImageUpload 弹层专项为 18 组布局、236 项断言，分别通过 Headless+Skia 和 macOS 原生后端；原生鼠标缩放、拖动平移和 Esc 关闭也已验证。以上记录来自对应实现阶段，本次打包不重复扩大全库行为验证。构建、包元数据和内容检查单独执行；不将构建通过视作 Windows/Linux 实跑，也没有进行全库回归或全库 AOT 发布。
