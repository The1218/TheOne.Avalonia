# 1.0.0-preview.8

**简体中文** · [English](../en/1.0.0-preview.8.md) · [文档入口](../../README.md)

本次准备 `TheOne.Avalonia` 与 `TheOne.Avalonia.DataGrid` 两个同版号安装包，NuGet 由维护者手动上传。源码或 GitHub Release 不代表 NuGet 已上架。框架保持 .NET 10 / Avalonia 12.1.4；主库程序集版本仍为 1.0.0.0，DataGrid 上游及程序集版本仍为 12.1.2 / 12.1.2.0。

## 相对 preview.7 的更新

- [OneIcon](../../controls/zh-cn/one-icon.md)：自有矢量图标共 20 类 320 个，32 个独立实心变体，其余明确回退为线性轮廓；支持枚举、绑定、主题和三档尺寸。覆盖常用、金融、工业、医疗、基础设施、交通、商业、教育、天气等分类，提供目录 API、独立预览与双语文档。
- OneIcon 画廊复用原生虚拟化行和 Button 槽位，缓存文字布局，减少控件创建、重复绑定和布局。真实 macOS 桌面 320 图标场景：打开 p95 从 310.50ms 降至 143.56ms，滚动更新 p95 从 33.48ms 降至 17.46ms，单次滚动 UI 托管分配中位数从 3,552,744 bytes 降至 114,896 bytes。测量终点为渲染线程批次完成，不是物理显示延迟；方法和限制见图标文档。
- [Breadcrumb](../../controls/zh-cn/breadcrumb.md)：路径、图标、分隔符、命令与原始参数，当前页不可导航；支持键盘、RTL、动态集合和编译绑定。补齐连续点击、命令重入、返回祖先、数据源切换、卸载重载及延迟焦点恢复边界。
- [DateTimePicker](../../controls/zh-cn/datetime-picker.md)：基于原生 CalendarDatePicker 的日期时间组合输入，支持 Format、可空 Time、双向绑定、保留时分秒、取消恢复、禁用与填充样式。复用原生校验、日期限制及弹出滚动隔离。
- [Timeline](../../controls/zh-cn/timeline.md)：垂直事件历史，支持左右/交错布局、倒序、间距、五种状态、自定义节点与模板、可观察 TimelineItemModel 和动态集合；末项尾线和模板恢复随数据更新，保留内容中的原生交互。
- [OneWindow / ThemeButton](../../controls/zh-cn/windows.md)：补齐标题栏显示、主题切换作用域与可选 Default/Light/Dark 三态周期；预览采用自定义品牌头部及相应窗口布局，保留正常演示入口。
- 双语控件指南、API/内置模型引用、迁移入口、版本说明及预览目录同步源码；保留图标最初设计稿并明确其概念图身份。控件/图表方案是规划，不表示其余图种已实现。
- 清理旧构建、截图、日志、轨迹、旧参考合并脚本和重复检出，保留仍可复用的本地验证源码。生产代码不保留历史参数测试入口。DataGrid 本轮无行为变化，仅随统一版本列车打包。

## 升级注意

```sh
dotnet add path/to/YourApp.csproj package TheOne.Avalonia --version 1.0.0-preview.8
```

1. 两包一起升级；不要同时引用官方 `Avalonia.Controls.DataGrid` 包。没有新增生产 NuGet 依赖。PreviewHost 的编辑器、打印及 MVVM 依赖不自动成为控件库依赖。
2. 图标几何与元数据可共享，Control 实例不能跨宿主共享。默认图标不捕获输入；Filled 仅对声明支持的图形使用独立资源。
3. Breadcrumb 不创建页面或删改路径，由宿主在命令/事件中更新路径。持久化业务 Key，不保存可视控件或显示文字代替身份。
4. DateTimePicker 不转换时区；日期边界不等于精确时间戳边界。通常仅绑定 SelectedDate，需要独立时间时再绑定 Time，避免宿主向两者强制推送冲突值。
5. Timeline 按集合顺序展示，Reverse 只影响视觉顺序，不排序或改变原生内容 Tab 顺序；默认面板非虚拟化，大量历史由宿主分页/按需加载。
6. ThemeButton 默认为 Light/Dark 两态；需要系统默认态时显式启用 IsThreeState，IsChecked 的 null/true/false 对应 Default/Dark/Light。窗口级与应用级切换遵循显式作用域及原生主题继承。

## 验证与发布边界

发布前构建 PreviewHost 并校验文档引用、生成契约、包内容、双包依赖、版本及源码提交元数据；没有执行全库回归。功能专项沿用前序实际记录：

| 范围 | 已执行专项 | 边界 |
| --- | --- | --- |
| OneIcon | 托管及 macOS ARM64 NativeAOT 各 10,709 项；真实桌面搜索、按钮/键盘与滚动；六张图集像素不变 | 打开/滚动数据含调度，不代表 Windows/Linux 或物理屏幕延迟 |
| Breadcrumb | 初版托管/AOT 各 205 项；后续生命周期 534 项、连续输入 570 项 | 后续仅交互变更未重复 AOT；不是全平台实跑 |
| DateTimePicker | 托管及 macOS ARM64 NativeAOT 各 55 项 | Headless + Skia 输入与绘制，不代表 Windows/Linux 原生窗口 |
| Timeline | 托管及 macOS ARM64 NativeAOT 各 426 项；真实桌面交互 | 仅时间线及预览，不含其他控件回归 |

上述是本轮功能实现时的专项证据，不冒充此次打包重新全量执行的结果。正常 Release 构建仍有既有 LoginDemoViewModel CS8620 可空警告；已有图标和时间线原生消费无新增裁剪/AOT 警告。

手动上传 NuGet 时先上传 `TheOne.Avalonia.DataGrid`，再上传 `TheOne.Avalonia`，等待验证和索引。发布包附 SHA-256 清单，nuspec 的 repository commit 指向对应源码；不要将远端 Release、源码 tag 或本地打包误认为 NuGet 上传完成。
