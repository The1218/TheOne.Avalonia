# 1.0.0-preview.6

**简体中文** · [English](../en/1.0.0-preview.6.md) · [文档入口](../../README.md)

本次同步准备 `TheOne.Avalonia` 与 `TheOne.Avalonia.DataGrid`。NuGet 包由维护者手动上传，GitHub Release 和本地打包不代表 NuGet 已上架。框架保持 .NET 10 / Avalonia 12.1.4；DataGrid 上游仍为 12.1.2，程序集身份不变。

## 相对 preview.5 的更新

- 新增 [QRCode](../../controls/zh-cn/qr-code.md)：UTF-8 / ECI 编码、指定纠错等级、静区和矢量绘制；无效内容清除旧码并报告错误。
- [ReportDesign](../../controls/zh-cn/report-design.md) 增加二维码组件，支持静态内容及字段绑定。设计、分页预览和 PDF 共用内容解析与编码规则；保存重载、数据源替换、撤销重做和并发导出隔离当前内容。
- 添加数据源改为校验步骤向导，按是否需要权限验证组织接口、Token/请求头、数据请求和数据项选择。配置变更、取消、重试会隔离旧响应。表格列支持左右插入及删除，并对齐列宽、字段、选择和撤销重做。
- PDF 导出在提交前保留原目标内容；本地保存通过同目录临时文件提交，处理覆盖、目标占用、权限失败、取消及重试。特殊存储提供程序的能力边界和失败处理见控件文档。
- [WorkflowEditor](../../controls/zh-cn/workflow-editor.md) 支持宿主绑定的审批人／角色多选、编译 Key/文本适配器和稳定 `SelectedKeys` 数组。自定义属性模板复用内置字段编辑器，对齐只读、提示、引用和撤销行为；节点库条目更紧凑，左右边栏支持原生分隔条调整宽度并保留实例内布局偏好。
- GanttChart 单任务更新避免重建整棵树和全部订阅。图表增量维护数据订阅、范围、堆积、抽样和绘制缓存，减少单点变化及选择更新的无关工作。性能条件、前后数据和仍未消除的 ScatterChart 光栅 p99 尾延迟见[图表绘制文档](../../controls/zh-cn/chart-rendering.md)，不承诺所有场景 p99 都改善。
- 模板普通绑定统一显式 `CompiledBinding`，保留原生 `TemplateBinding`；修复具体数据模板的类型识别。DataGrid 模板补丁记入 vendor README。
- PreviewHost 移除历史专项、消费探针及 Program/App 中的测试参数分支，保留正常演示入口；更新独立控件预览、双语 API 与迁移文档。

## 升级注意

```sh
dotnet add path/to/YourApp.csproj package TheOne.Avalonia --version 1.0.0-preview.6
```

显式引用 DataGrid 的项目同步升级 `TheOne.Avalonia.DataGrid`；不要同时引用官方同名程序集包。主包新增的 `Net.Codecrete.QrCodeGenerator` 3.2.1 由 NuGet 自动还原，许可随第三方声明提供。

`WorkflowValueKind.MultiSelect = 3` 与 `ReportElementKind.QRCode = 8` 均追加到枚举末尾。旧文档的原有类型仍可读取；旧版库不能读取包含新增类型的新文档。多选持久化稳定身份 Key，不保存显示名称或候选数据源。业务执行、人员／角色查询和运行时数据加载仍由宿主管理。参考[迁移指南](../../integration/zh-cn/README.md)及对应控件文档。

## 验证与交付边界

沿用每次仅验证受影响控件的约定，本次发布未执行全库回归。前序专项的数值和环境条件保留在相关控件指南；本轮 WorkflowEditor 最新边栏／密度专项 35 项通过，属性模板托管及 osx-arm64 AOT 专项各 32 项通过，审批人绑定托管及 AOT 专项各 128 项通过。布局与输入使用当前 macOS 宿主上的 Skia/Headless，不能据此声称 Windows/Linux 或物理设备实跑通过。

发布准备检查项目构建、文档相对链接、包版本／依赖／程序集及仓库提交信息，不把这些检查写成运行时全量验证。旧构建目录、截图、日志及 PDF 测试产物清理，保留有效探针源码、简要验证记录和性能测量数据。

手动上传时先上传 `TheOne.Avalonia.DataGrid`，再上传 `TheOne.Avalonia`，等待 NuGet 验证和索引完成；具体源码对应包内 repository commit，安装包附 SHA-256 清单。
