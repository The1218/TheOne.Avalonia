# 1.0.0-preview.9

**简体中文** · [English](../en/1.0.0-preview.9.md) · [文档入口](../../README.md)

本次生成 `TheOne.Avalonia` 和 `TheOne.Avalonia.DataGrid` 两个同版号 NuGet 包，由维护者手动上传。源码推送和本地打包不表示 NuGet 已上架。框架保持 .NET 10 / Avalonia 12.1.4，主库程序集版本保持 1.0.0.0，DataGrid 上游及程序集版本保持 12.1.2 / 12.1.2.0。

## 相对 preview.8 的更新

- 新增 [Heatmap、Radar、Funnel](../../controls/zh-cn/chart-specialized.md)、[BoxPlot、Candlestick](../../controls/zh-cn/chart-statistical.md) 和 [Treemap、Sunburst](../../controls/zh-cn/chart-hierarchy.md)。补齐可观察数据模型、主题资源、选择与命中、导出、层级下钻、独立预览和双语 API 说明。这是七种图表的落地，不表示已实现 ECharts 全部能力。
- 图表复用统一动画配置，区分首次展示和后续变化，遵守禁用、减少动效及复杂数据预算；完善订阅、范围、几何、文本和绘制缓存。新增图表的语义、样本规则及限制见对应指南。[首批性能记录](../../controls/zh-cn/chart-echarts-performance-20261020.md)与[第二批性能记录](../../controls/zh-cn/chart-next-batch-performance-20261020.md)分别说明测量方法及适用范围。
- [AttachmentList](../../controls/zh-cn/attachment-list.md) 支持多文件选择、可绑定文件集合、状态进度、预览事件和移除命令，明确取消、迟到结果和文件所有权。上传、下载、授权和业务附件关系仍由宿主负责。
- [WorkflowEditor](../../controls/zh-cn/workflow-editor.md) 增加连接属性模板、连接创建工厂、节点创建/删除策略，以及可观察连接元数据；连接配置纳入文档修订、撤销重做和序列化。[DialogContext](../../api/zh-cn/TheOne.Avalonia.Controls.DialogContext.md) 开放派生类的计算属性变更通知。
- [DataGridRowNumbers](../../controls/zh-cn/datagrid-extensions.md) 提供显式启用的原生行头序号、分页偏移和宽度配置，响应排序、筛选及行容器复用，关闭后恢复原设置。该能力位于主库，vendor DataGrid 本轮无行为改动。
- 预览页按视口延迟创建说明和示例；已访问页面保留实例，减少返回时说明区与代码编辑器重新挂载，保留草稿、选择、光标、焦点和撤销状态。移除所有控件页共用的底部源码展开框及空说明占位，内联短代码保留在 `Description` 中。[返回性能记录](../../controls/zh-cn/preview-return-performance-20261020.md)：Line / Button / NavPage 在完整浏览后的返回 p95 分别为 941.8→19.9 / 948.2→19.8 / 316.3→17.2ms；这是当前 macOS 工作负载到首次原生帧回调的测量，不是 GPU 呈现耗时。
- 同步双语指南、完整公共契约与预览目录；更新安装、迁移及发行入口。清理历史重复构建、运行时副本和旧安装包，保留有效验证源码及性能样本。

## 升级

```sh
dotnet add path/to/YourApp.csproj package TheOne.Avalonia --version 1.0.0-preview.9
```

1. 两包一起升级；不要同时引用官方 `Avalonia.Controls.DataGrid` 包。本轮没有新增生产 NuGet 依赖；PreviewHost 的编辑器、打印及 MVVM 依赖不会进入主库依赖。
2. 统计和层级图表使用各自数据模型，不把 OHLC、箱线摘要或树节点当成普通 XY 数据。主库仍直接绘图，不按点创建控件。
3. 已访问的预览页保留更久，尚无 LRU 驱逐；隐藏页不参与布局和绘制，但业务订阅可能继续接收更新。首次帧数字不能代表完整浏览成本、物理显示延迟或所有机器的上限。
4. 附件命令接受文件后，宿主负责释放文件资源及业务取消；工作流持久化使用 `WorkflowSerializer.Save/Load`，执行、权限及接口调用由宿主负责。

附件、行号、工作流和对话框的本地验证源码保留在 `.preview/pengpai-*`，这些记录不冒充本次重新执行或跨平台实跑。Release 构建仍有既有 `LoginDemoViewModel` CS8620 可空警告。此次没有 Windows/Linux 实跑、整库回归或全库 AOT 发布。
