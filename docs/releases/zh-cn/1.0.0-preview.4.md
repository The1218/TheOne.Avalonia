# 1.0.0-preview.4

**简体中文** · [English](../en/1.0.0-preview.4.md) · [文档入口](../../README.md)

本版同步准备 `TheOne.Avalonia` 和 `TheOne.Avalonia.DataGrid` 两个包；是否已可安装以 NuGet 源的实际状态为准。框架仍为 .NET 10 / Avalonia 12.1.4，DataGrid 上游仍为 12.1.2，程序集身份保持不变。

## 相对 preview.3 的更新

- 控件文档与独立预览页按 Classes 样例、额外属性、业务 API 和关联模型组织；属性和业务动作附短代码片段，通用尺寸与动效集中在 Home。新增 Description 说明列表与接入迁移指南。
- MultiSelectBox 弹层使用独立有限视口，滚轮停留在弹层内，避免带动外部页面；超出内容时显示原生纵向滚动条。
- 修复标签拖到末项之后松开时标题消失，以及虚拟化 Item 重排、移除再插入、Replace、Reset 和切换 ItemsSource 后的挂载、选择身份和旧数据残留。
- 菜单滚动按钮使用紧凑高度；短菜单完整测量，修复首次原生 ContextMenu 高度不足、误显示滚动按钮和文字裁切。长菜单保留虚拟化，跨面板切换时先清理旧容器。
- 补充双语菜单／集合生命周期说明，保持窗口 owner、消息路由、主题切换及可选编辑器／打印依赖说明。

## 升级

```sh
dotnet add path/to/YourApp.csproj package TheOne.Avalonia --version 1.0.0-preview.4
```

显式引用 `TheOne.Avalonia.DataGrid` 的项目同步升级到 `1.0.0-preview.4`，不要同时引用官方 `Avalonia.Controls.DataGrid`。普通消费应用不需要 PreviewHost、验证代码或本机 Skill。

既有主题、业务命令和模型绑定入口保持不变。自定义 ItemsPanel 或完整模板会覆盖主题默认布局，需自行检查首次测量、有限视口和容器生命周期。迁移细节见[接入指南](../../integration/zh-cn/README.md)。

## 验证边界

近期修复使用对应控件专项验证，未做全量回归。菜单首开在 macOS 原生窗口验证明暗主题、三档尺寸、窄窗口和混合项高；原生首开布局与绘制、Headless 指针／键盘交互及 osx-arm64 NativeAOT 菜单消费检查分别执行。桌面实鼠标悬停受系统权限限制，不计为通过。构建或跨 RID 产物检查不代表 Windows、Linux、移动端或浏览器实跑。

本版发布准备还检查双语目录、文档链接、源码契约漂移、业务示例编译和包内元数据。准确源码版本以包内 nuspec 的 repository commit 为准；当前包未附完整 XML API 说明，精确声明见[源码契约](../../api/zh-cn/README.md)。
