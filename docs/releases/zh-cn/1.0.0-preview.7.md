# 1.0.0-preview.7

**简体中文** · [English](../en/1.0.0-preview.7.md) · [文档入口](../../README.md)

本次同步发布源码与发行说明，并准备 `TheOne.Avalonia`、`TheOne.Avalonia.DataGrid` 两个安装包，NuGet 由维护者手动上传。GitHub Release 不代表 NuGet 已上架。框架保持 .NET 10 / Avalonia 12.1.4；主库程序集版本 1.0.0.0、DataGrid 上游 12.1.2 及程序集身份 12.1.2.0 均不变。

## 相对 preview.6 的更新

- 新增 [TreeSelect](../../controls/zh-cn/tree-select.md)：稳定 Key 的单选/多选、Independent/Cascade 父子规则、三态、搜索保留祖先、禁选项、标签上限、键盘和虚拟化。默认 TreeSelectNode 与强类型适配器支持原始模型，模板使用编译绑定；替换源、Reset/Replace、选择及展开按 Key 核对。提供独立预览、Home 入口、双语 API 和使用文档。
- [Button、ToggleButton、RepeatButton](../../controls/zh-cn/basic.md#button语义色与外观组合) 及 [IconButton](../../controls/zh-cn/icon-button.md) 分离语义色与外观，支持 `danger outline`、`success soft` 等组合，新增显式 `solid`。颜色优先级为 info > warning > success > danger > primary/accent；外观为 gradient > soft > outline > link > ghost > solid，不依赖 Classes 添加顺序。保留原生三态、长按重复、图标布局和加载行为。
- [Tag](../../controls/zh-cn/tag-verification-step.md) 新增 pill、square、dashed、dot、gradient；修复动态切换 Status、Variant、Classes、主题与禁用时的配色、圆角和虚线残留。
- [TabControl](../../controls/zh-cn/collections.md) 内容默认 Padding 统一为 8 DIP，普通/card/One.CardTabControl 一致。切换模板时先释放旧视觉宿主，保留内容实例、编辑值及选择；标题容器重新挂载时刷新当前主题与密度。
- [ColorPicker](../../controls/zh-cn/color-picker.md) Custom 弹层不再继承通用 Flyout 的 480 DIP 上限，随当前内容自然展开；空间不足仍保留原生定位及滚动。
- 保存[扩展控件和图表路线图](../../plans/control-and-chart-roadmap.md)，区分已有能力、图种缺口与后续坐标/数据映射设施。路线图不表示尚未实现的能力已进入安装包。
- DataGrid 本次没有行为变更，仅随统一版本列车打包。

## 升级注意

```sh
dotnet add path/to/YourApp.csproj package TheOne.Avalonia --version 1.0.0-preview.7
```

1. 显式引用 DataGrid 配套包时一并升级，不要与官方同名程序集包共存。没有新增 NuGet 依赖。
2. 单独按钮 Classes 保留原有启用外观，但禁用配色统一为 DisabledSurface/DisabledText/Line；ToggleButton 已选中/空值态使用 DisabledSelection。旧版依赖特殊禁用配色的页面需核对。需要各按钮统一实心效果时使用 `primary solid`，不假定旧 `primary` 在所有派生控件中相同。
3. TabControl 依赖旧内容间距的页面应显式设置 Padding；不再给示例内容叠加额外 Margin。现有本地 Padding 仍优先。
4. TreeSelect 持久化业务 Key，不保存显示名或展示行。自定义模型使用强类型 getter；初始数据尚未加载时可暂用 null 源，首个非 null 源会清理缺失 Key。级联仅保存可用叶子，禁用叶子已有选择保留；搜索不缩小级联范围。
5. TreeSelect 首版刷新会扫描完整模型树，虚拟化的是视图；异步子项请求、取消和业务权限由宿主处理。地图、雷达、热力等路线图项目尚未实现。

## 验证与交付边界

本轮仅构建所需项目并检查文档、包元数据和仓库状态，没有执行全库回归。前序各专项记录：Tag 50,780 项及 192 次绘制对照；TabControl 5,725 项；Button 25,695 项；ToggleButton/RepeatButton/IconButton 托管与 osx-arm64 AOT 各 175,119 项；ColorPicker 84 项；TreeSelect 托管与 osx-arm64 AOT 各 172 项。一万零一个展开节点的测试视口仅实现 7 个行容器，这不是所有视口固定的容器数。

布局和输入在 macOS ARM64 的 Avalonia.Headless + Skia 中验证，不能据此声明 Windows/Linux 桌面或物理触摸设备实跑通过。TreeSelect 触摸/惯性滚动有边界处理实现，专项实际滚动输入覆盖滚轮。原生 AOT 消费验证无新增裁剪警告；既有无关 LoginDemoViewModel CS8620 构建警告仍保留。

上传 NuGet 时先上传 `TheOne.Avalonia.DataGrid`，再上传 `TheOne.Avalonia`，等待验证和索引完成。包内 repository commit 标识对应源码；Release 附包及 SHA-256 清单。
