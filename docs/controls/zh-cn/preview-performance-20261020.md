## 预览内容规则

预览页的额外属性说明仅保留本项目公开、可写且可绑定的属性：控件的 Avalonia 属性、附加属性，以及关联模型的公开可写属性。支持 `Binding` 和 `CompiledBinding`，不按默认绑定模式是否为 `TwoWay` 筛选。默认 `OneWay` 的可写属性仍可显式指定 `Mode=TwoWay`；应用负责提供正确的 `x:DataType`、数据上下文和变更通知。

不展示原生继承属性的重复说明、只读运行状态、静态字段、init-only 成员和内部标识符；模型没有可写属性时，不创建空说明区。枚举选项仍在对应属性的可选值中展示，不再创建单独枚举清单。这里仅精简预览展示，不删除控件属性、模型成员或[完整公开契约](../../api/zh-cn/README.md)。

业务 API 保留保存、加载、导出、校验、撤销等实际操作及短代码示例；不把属性 Get/Set 包装方法、构造器、属性标识符混入 API 区。Classes 继续通过实际样例对照，共用尺寸、主题和动效设置统一在 Home 说明。

## 实现

- 共用的属性、业务 API、模型说明进入可视区后创建；每组最多六行 `Description`，避免一次创建整页说明控件。保留全部过滤后的内容，滚动后继续创建后续分组。
- 样式矩阵延后挂载屏幕外的样例；Button / Input / Select 合并页不再创建内容策略明确不展示的原始演示实例。
- 示例代码编辑器首次进入可视区才创建；底部源码编辑器首次展开才创建，后续切换文件复用实例。延迟期间修改文本、语言和尺寸，创建时读取最新值。
- 普通切页重置滚动位置不再强制同步 `UpdateLayout()`，也不再由窗口重复重置；指定控件分区的跳转仍先取得真实布局位置，并用请求序号取消过期滚动。
- 占位高度仅用于首次测量，创建后按实际内容布局，不固定说明区高度。已创建实例保留，滚出视口不会重建业务状态。
- 尚未创建的交互内容保留键盘入口；Tab / Shift+Tab 同步进入真实子控件，跳过禁用项，创建后移除占位的 Tab 停靠。不使用延迟焦点恢复。

## 测量边界

环境：macOS、Apple M4、.NET 10、Avalonia 12.1.4，Release，1100 × 820 窗口，真实桌面后端。通过 `GalleryViewModel.Select` 打开完整 `ControlGallery`，包含页面包装、说明区与源码面板；不是只测孤立 Chart。计时止于首次原生动画帧回调，包含同步创建和布局，**不代表 GPU 呈现完成时间**。

修改前后使用同一控件库、主题和依赖程序集，仅替换 PreviewHost，排除工作区其他改动的影响。未缓存打开：每次使用新的 Gallery，第一项单列，随后 Line / Gauge 各十项、Button 五项用于热态统计。p95 使用 nearest-rank，小样本下接近最大值，仅用于此次对照，不是稳定尾延迟承诺。进程启动、初始窗口创建不在导航计时内。

日志、JSON、截图和临时探针位于 `.preview/preview-open-20261020/`，不进入正常启动代码，也不作为控件库公共 API。

`before-shared-native-*` 与 `final-native-*` 保存原始样本和程序集 SHA-256。共同控件库 SHA-256 为 `16b3a724cbaef4bb2154182870b8319bc6db2dacc8324f32c995046bcab926f7`；最终 PreviewHost 为 `ef7695030e078b82d00ddf0e2a76402328ee4a9da49f6c2e32951c285ad9c0a6`。多次进程测量仍有波动，不能把此次单组中位数视为每次打开的保证；Button p95 仍有明显剩余成本。

## 验证范围与剩余成本

仅构建 PreviewHost，专项验证共用预览展示层及其明确受影响调用方。真实桌面后端通过 2009 项检查：元数据规则、Line / Gauge / Button / Input / Select / NavPage、全页滚动、明暗主题、三档尺寸、窄窗口、指定分区跳转、源码展开与切换、快速导航、卸载重载、延迟内容正反向 Tab、禁用项和最新代码配置。过滤后 Line 说明由首屏两行增长到完整 87 行、Gauge 从零行增长到完整 116 行；没有用截断列表换取打开速度。

另以真实指针和按键检查最终 MainWindow：通过菜单搜索进入 LineChart，展开源码后显示正确文件，Tab / Shift+Tab 在源码文件选择器和复制按钮间切换；关闭源码后，Shift+Tab 可进入尚未创建的业务 API 说明，创建后可继续正反向导航。Small / Normal / Large 的窄窗口明暗截图已检查换行与裁剪。临时验证窗口已关闭，正常 Program / App 没有增加测试分支。

首次滚动到新说明分组、复杂业务示例或代码编辑器时，仍需要创建、布局或高亮；已完整浏览页面保留其实例和状态，因此返回页面仍可能产生重新挂载成本。此次没有修改控件库的绘制、业务数据或绑定契约，没有进行全控件功能回归、AOT 消费测试或 Windows / Linux 实跑。正式性能判断应继续使用目标机器和真实业务页面测量。
