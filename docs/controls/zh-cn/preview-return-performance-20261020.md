# PreviewHost 完整浏览后的返回优化（2026-10-20，第二阶段）

[English](../en/preview-return-performance-20261020.md) · [第一阶段记录](preview-performance-20261020.md) · [控件文档](README.md)

## 改动

第一阶段减少了首次打开的创建量，但完整浏览后，返回仍会把说明区和代码编辑器重新挂载。本阶段引入预览专用的 `PreviewPageHost`：已访问页面保留在树中，由独立容器隐藏非当前页；只测量、排列当前页，隐藏页不参与绘制、命中或键盘导航。页面、说明行、代码编辑器和业务模型不因正常切页而重建。

移除了所有控件页共用的底部「示例代码 · AXAML / C#」展开框、文件选择器及对应加载代码，也停止嵌入整套 Views / ViewModels 演示源码。Home 和必要业务示例的内联代码编辑器保留，属性和业务 API 的短代码仍直接放在对应 `Description` 中。

创建说明占位前，先根据实际筛选后的属性、业务 API 和模型判断是否有内容。SplitButton 等没有说明行的页面不再预留 320px 的空区域；空补充容器也不会额外引入布局间距。非空说明仍可按需创建并使用自然高度，没有压缩或隐藏真实说明内容。画布编辑器继续使用有限视口。

## 状态和焦点

- 已选数据、编辑草稿、代码文档、代码选区、光标及撤销历史保存在原实例中。
- 文本框的原生焦点行为会折叠选区，因此预览宿主仅跟踪每页最后编辑的文本框，同步保留并恢复其选区、光标；数据变短时按有效长度截断，已移出页面的目标不恢复。
- 从页面内容发起的导航可恢复目标页先前的编辑焦点及编辑位置；菜单、搜索框或其他外部入口仍持有自己的焦点。返回时可恢复文字选区，不抢走菜单焦点。不使用异步焦点恢复回调。
- 缓存页隐藏不等于卸载。宿主只跟踪当前页已打开的 Popup，切页和卸载时关闭这些瞬态浮层，保留属性绑定与选择数据；正常切页无需扫描全部说明或编辑器来寻找浮层。
- 真正卸载整个预览宿主时，仍走 Avalonia 的原生卸载流程，并释放浮层观察订阅。

## 桌面测量方法

macOS / Apple M4、.NET 10、Avalonia 12.1.4、Release，1100 × 820 窗口，真实桌面后端。同一探针、同一控件库和依赖，仅替换 PreviewHost。每组先打开并完整滚动目标页，再交替 Home / 目标页；完整遍历和 Home 导航不计入返回计时。统计其后 30 次热态返回，p95 使用 nearest-rank。

计时从 `GalleryViewModel.Select` 到首次原生动画帧回调，包含同步导航和布局，**不是 GPU 呈现完成时间**。仅在首末样本统计可视树，避免每轮树遍历引入的分配和 GC 干扰；因此不要与第一阶段的小样本数字直接相减。结果是承载层、去除底部面板及空占位修复的组合效果；去除面板后，同尺寸窗口的可用内容区略大。

原始样本、挂载计数、日志、截图与临时探针放在 `.preview/preview-return-20261020/`，不进入正常 Program / App 启动逻辑。正常预览仍为 WinExe；控件库公共 API、编译绑定和业务模型契约不变。

## 专项验证

仅构建 PreviewHost，真实桌面后端通过 **151 项**检查：Line / Gauge / Button / Input / Select / NavPage 的完整滚动与返回，图表选择、说明行与编辑器实例不丢失；明暗主题、三档尺寸及窄窗口的 SplitButton 自然高度与像素检查；文本框草稿、选区、光标和焦点；外部导航不抢焦点；ComboBox、MultiSelectBox 离页关闭浮层而保留多选数据；内联编辑器草稿、选区、光标、实际输入后的撤销历史与焦点保持。

另在最终 MainWindow 使用真实指针和键盘验证 Home / Input 返回：两页草稿均保留；选中末尾三个字符后往返，再输入 `XYZ`，正确替换同一段选区；焦点恢复到原字段，Tab 进入 Home 的下一个控件而非隐藏页。编辑器焦点和撤销状态由上述桌面专项验证。诊断快捷键仅存在于 `.preview` 临时探针，验证窗口已关闭。

## 边界

此缓存策略只延续已经访问的页面，不提前创建所有页面。代价是已创建的视图和原生渲染资源保留更久，没有增加 LRU 驱逐；页面很多时需继续观察内存。隐藏页不布局或绘制，但其模型订阅仍可接收业务更新，不能把它等同于销毁页面或取消后台业务。

验证只覆盖受影响的预览承载、说明、代码和代表页，没有全控件回归、AOT 消费验证或 Windows / Linux 实跑。
