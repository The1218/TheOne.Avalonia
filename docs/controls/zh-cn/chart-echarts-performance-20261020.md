## 本轮范围与结果

按用户确认的[原方案第一批](../../plans/chart-echarts-gap-and-optimization.md)，增加 HeatmapChart、RadarChart、FunnelChart；为 17 种 ChartBase 图表提供统一 Auto / None / Fade / Reveal 动画，保留已有系列、抽样、命中、选择和原始数值语义。地图、网络、Sankey、层级图等后续批次仍未实现。GanttChart 不在本轮统计图表改动范围。

- 新图表复用引用计数数据订阅及原生绘制管线，不为数据点创建 Control。
- Cartesian 动画在每次过渡准备阶段建立索引和可复用插值帧，tick 原位写坐标，不再逐帧构造系列、数组、字典和帧对象；动画帧回调委托复用。
- Pie / Doughnut 为每个扇区保留最近一次几何与标签缓存，静止重绘复用；中断动画不累计历史帧链。
- Heatmap 对确定不重叠的格子按最多 256 色合批；重叠格、透明叠加与标签保持源顺序，避免绘制结果与命中不一致。命中使用屏幕空间桶；Heatmap／Funnel 不重复保存基类的默认命中表。
- 几何／图例查询不消耗首次展示动画；禁用、关闭 Motion、卸载和样式切换会结束旧动画。PNG 为目标快照。
- Radar 卸载释放轴订阅，普通 Axes IList 修改后调用 RefreshData 会协调新旧轴订阅。Funnel 密集阶段使用实际可用高度并裁剪在绘图区内。

## 测量环境与方法

宿主：Apple M4、macOS 27.0.1、.NET SDK 10.0.100、Release 构建。比较基线为提交 `2cb58c5` 上本轮图表改动前冻结的主库程序集；工作区其他控件改动保留，没有纳入图表性能判断。

测量分为三类，不能相互替代：

1. **插值准备 CPU**：在真实 Avalonia.Native 进程中，对固定起止帧反复改变插值进度，预热 100 次，采样 800 次；原始输入为 Line 2000／6000 点、Bar 1000 点，沿用原默认抽样规则，准备帧分别保留 709／832／1000 个标记。这不是完整绘制时间。
2. **Skia 离屏重绘 CPU**：在同一原生进程中，复用 640×360 RenderTargetBitmap，直接调用 Chart.Render；预热 25 次，采样 140 次。Pie／Doughnut 各 64 扇区，其余为 2000 原始点。包含离屏绘制提交及该线程分配，不包含显示器呈现或全部 GPU 执行时间。
3. **真实桌面帧调度**：Avalonia.Native 实窗中，RequestAnimationFrame 连续使图表失效，每 18 次回调更新数据，动画时长 500 ms，记录每种图表 129 个回调间隔。该数据包含宿主刷新节奏，不能称为 GPU 光栅耗时。

线程分配由 GC.GetAllocatedBytesForCurrentThread 测量。计时器本身每组约 40 B，800 次摊销约 0.05 B／次；表中的“0”指插值路径在预热后没有观察到逐 tick 分配，不代表整个渲染系统零分配。p95 为排序后的样本分位；本轮样本量不足以对偶发 p99 作强结论。

主要静止重绘收益来自径向几何缓存。Line／Bar／Scatter 的静止绘制不是本轮优化的重点，上表保留没有改善和变慢的原始结果，不能宣称所有图表每个场景都变快。

Bar 额外定向复测：禁用 tiered JIT，每版 3 轮、每轮预热 50 次并测 500 次，核对实际加载 DLL 路径与 SHA-256。

| 顺序 | 基线三轮 p95，ms | 新版三轮 p95，ms |
| --- | --- | --- |
| 基线→新版 | 1.9245 / 1.9240 / 1.9251 | 2.6660 / 2.8215 / 2.9189 |
| 新版→基线 | 3.2486 / 3.0660 / 2.9436 | 3.0594 / 3.1349 / 3.2300 |

反序后的基线 p50 为 2.4873 / 2.5094 / 2.5170，新版为 2.5853 / 2.4980 / 2.4706，分配一致约 51,311 B／次。结果受到运行顺序、JIT 与机器状态的显著影响；两组都保留，不选择其中一组宣称稳定收益或代码回退。此场景的结论是**未确认改善，也未建立稳定回退的证据**。其绘制路径没有新增逐柱数据处理，本轮不再依据噪声追加优化。

## 专项验证范围

仅验证本轮新增或受共享动画／缓存改动影响的图表，没有全库回归。验证入口和产物隔离在 `.preview/chart-echarts-20261020/`，PreviewHost 的 Program／App 不增加测试参数。

- 17 种图表的 Auto／Fade／Reveal／None、首次展示、动态关闭动画、Motion、禁用、卸载重挂、导出不改变实时动画。
- 原有图表选择、几何位置与目标 PNG；17 种图表×明暗×三档尺寸，窄 260×220 视口共 102 张 PNG，并检查新增类型样例。
- 新图表的有限极值、NaN 缺口、负值／零值、动态点与来源替换、Radar 轴集合 Reset／Replace／普通 IList 刷新、排序后源索引和梯形边界命中。
- 热力图重复坐标／部分重叠的显示与命中一致性，Classes 冲突及局部属性优先级，首次查询后仍有入场动画。
- PreviewHost 仅构建该项目，核对新增三个独立页面、Description 说明和编译绑定；构建中的 LoginDemoViewModel 可空性警告是既有无关警告。实例化／卸载页面还记录到已有 ComboBox 模板的 SelectionBoxItem／IsEditable 空模板父级警告，没有新增图表或 ViewModel 属性解析错误；完整日志保留，不扩展修改该无关模板。

本轮完成结果：原生窗口动画检查 259 项、Headless＋Skia 首轮逻辑／导出／矩阵检查 188 项通过；最终程序集追加的新增图表／页面／样式检查 111 项、首次查询后入场动画检查 3 项通过。这些批次有重叠，不相加为互不重复的用例数。

macOS 原生 CUA 真实输入已通过：Heatmap／Radar／Funnel 各点击源索引 2，Right 移至索引 3，辅助功能描述随之更新；Escape 清除漏斗选择。没有用属性赋值或合成路由事件替代此输入验证，临时窗口已正常关闭。Windows／Linux 仍未实跑。

最终身份校验确认基线有 14 种 ChartKind 且无 AnimationStyle；新版有 17 种且具备该属性。冻结基线 DLL SHA-256 为 `f90c318333bee026ab81c964925262edc43f24beb043e781aebe9c4b22d9d8a2`，最终功能验证 DLL 为 `9033917f4ff9c95210be9cdb1b9e1d76c48532a6a4eaf92a4e29f9d8d1817c29`，实际加载路径保留在 baseline-identity／final-identity 的 metrics.json。性能采样在本轮优化版冻结产物上进行，后续边界修复使用最终 DLL 定向复核，没有把每次功能复核当成一次新的全量性能测试。

原始数据分别位于该任务目录的 baseline-native、after-native、baseline-raf、after-raf 子目录的 metrics.json；基线冻结产物、探针源码、构建日志和 PNG 同目录保留，均为可清理的本地专项产物。本记录保留可审阅的主要数据与测量口径。
